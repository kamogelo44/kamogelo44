A live, deployed REST API for discovering local services — clinics, taxi ranks, government offices, libraries, and police stations.

- **Layered architecture**: controllers → services → repositories → entities
- **Spring Data JPA** with derived queries, pagination, and sorting
- **JWT authentication** with BCrypt password hashing
- **DTO layer** separating API contracts from entity structure
- **Global exception handling** with clean JSON error responses
- **Bean validation**, audit fields, and Swagger UI documentation
- **Unit tested** with JUnit 5 and Mockito
- **Dockerized** and **deployed to Railway** with a managed MySQL database
- Built with **Java 25, Spring Boot 4.1, MySQL, Docker**

**Live API:** https://local-services-api-production.up.railway.app
