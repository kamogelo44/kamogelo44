## Featured Projects

### ConsuTrade
A C2C e-commerce marketplace built for South Africa's informal economy. Includes seller dashboards, buyer browsing, order management, and payment processing.
**Stack:** PHP, MySQL, JavaScript/jQuery, PayFast

### Local Services Directory API
A REST API for searching local services such as clinics and government offices, with JWT-secured endpoints and third-party API integration.
**Stack:** Spring Boot, Java, Spring Data JPA, MySQL, Maven
